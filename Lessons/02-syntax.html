Java Syntax & Basics

Before writing real programs, you need to understand the building blocks: variables, data types, operators, and how Java's syntax is structured.

Variables

A variable stores a value. In Java you must declare its type before using it.

Variables.java
public class Variables {
    public static void main(String[] args) {
        int age = 25;
        double price = 9.99;
        char grade = 'A';
        boolean isJavaFun = true;
        String name = "Alice";

        System.out.println(name + " is " + age + " years old");
    }
}
▶ Output: Alice is 25 years old

Type Casting

Converting between types can be widening (automatic) or narrowing (manual).

Casting.java
int x = 9;
double d = x;            // widening – automatic
int y = (int) 9.99;     // narrowing – manual, loses .99
System.out.println(d);   // 9.0
System.out.println(y);   // 9

Operators

Arithmetic Operators

Operators.java
int a = 10, b = 3;
System.out.println(a + b);  // 13  – addition
System.out.println(a - b);  // 7   – subtraction
System.out.println(a * b);  // 30  – multiplication
System.out.println(a / b);  // 3   – integer division
System.out.println(a % b);  // 1   – modulus (remainder)

Constants (final)

Use the final keyword to declare a constant — a value that cannot change:

Constants.java
final double PI = 3.14159;
final int MAX_SPEED = 120;
System.out.println("Pi = " + PI);
▶ Output: Pi = 3.14159
⚠️ Convention: Constants are named in UPPER_SNAKE_CASE by Java convention.
