Control Flow

Control flow statements let your program make decisions and repeat actions. Java provides if/else, switch, and three kinds of loops.

if / else if / else

IfElse.java
int score = 75;

if (score >= 90) {
    System.out.println("Grade: A");
} else if (score >= 70) {
    System.out.println("Grade: B");
} else if (score >= 50) {
    System.out.println("Grade: C");
} else {
    System.out.println("Grade: F");
}
▶ Output: Grade: B

Ternary Operator (shorthand if)

Ternary.java
int age = 20;
String status = (age >= 18) ? "Adult" : "Minor";
System.out.println(status);
▶ Output: Adult

switch Statement

Use switch when comparing a variable against several specific values:

Switch.java
int day = 3;
switch (day) {
    case 1: System.out.println("Monday");    break;
    case 2: System.out.println("Tuesday");   break;
    case 3: System.out.println("Wednesday"); break;
    case 4: System.out.println("Thursday");  break;
    case 5: System.out.println("Friday");    break;
    default: System.out.println("Weekend");
}
▶ Output: Wednesday
⚠️ Don't forget break! Without it, Java "falls through" to the next case.

for Loop

Use when you know exactly how many times to repeat:

ForLoop.java
for (int i = 1; i <= 5; i++) {
    System.out.println("Lap " + i);
}
▶ Output: Lap 1 … Lap 5

while Loop

Use when you don't know in advance how many iterations you need:

WhileLoop.java
int n = 1;
while (n <= 4) {
    System.out.println("n = " + n);
    n++;
}
▶ Output: n = 1 / n = 2 / n = 3 / n = 4

do-while Loop

Runs the body at least once, then checks the condition:

DoWhile.java
int count = 0;
do {
    System.out.println("Count: " + count);
    count++;
} while (count < 3);
▶ Output: Count: 0 / Count: 1 / Count: 2

break and continue

BreakContinue.java
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;  // skip 3
    if (i == 6) break;     // stop at 6
    System.out.print(i + " ");
}
▶ Output: 0 1 2 4 5
