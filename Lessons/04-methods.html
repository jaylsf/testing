Methods

Methods are reusable blocks of code that perform a specific task. They keep your code organized, readable, and DRY (Don't Repeat Yourself).

Defining a Method

Syntax
returnType methodName(paramType paramName, ...) {
    // method body
    return value; // only if returnType != void
}

void Methods (no return value)

Greet.java
public class Greet {
    static void sayHello(String name) {
        System.out.println("Hello, " + name + "!");
    }

    public static void main(String[] args) {
        sayHello("Bob");
        sayHello("Alice");
    }
}
▶ Output: Hello, Bob! / Hello, Alice!

Methods with Return Values

Calculator.java
public class Calculator {
    static int add(int a, int b) {
        return a + b;
    }

    static double average(double x, double y) {
        return (x + y) / 2;
    }

    public static void main(String[] args) {
        int sum = add(10, 5);
        System.out.println("Sum: " + sum);
        System.out.println("Avg: " + average(10.0, 6.0));
    }
}
▶ Output: Sum: 15 / Avg: 8.0

Method Overloading

Java allows multiple methods with the same name but different parameter types or counts. The compiler picks the right one:

Overload.java
static int    multiply(int a,    int b)    { return a * b; }
static double multiply(double a, double b) { return a * b; }
static int    multiply(int a,    int b, int c) { return a * b * c; }

System.out.println(multiply(3, 4));        // 12
System.out.println(multiply(3.0, 4.5));   // 13.5
System.out.println(multiply(2, 3, 4));    // 24

Recursion

A method can call itself. A classic example is calculating a factorial:

Factorial.java
static int factorial(int n) {
    if (n == 0) return 1;        // base case
    return n * factorial(n - 1);  // recursive call
}

System.out.println(factorial(5)); // 120
▶ Output: 120
✅ Tip: Always have a base case in recursion to prevent infinite loops.
