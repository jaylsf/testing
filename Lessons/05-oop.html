Object-Oriented Programming

Java is built around OOP. Classes are blueprints; objects are instances. The four pillars are Encapsulation, Inheritance, Polymorphism, and Abstraction.

Classes and Objects

Dog.java
public class Dog {
    // Fields (attributes)
    String name;
    String breed;
    int age;

    // Constructor
    Dog(String name, String breed, int age) {
        this.name  = name;
        this.breed = breed;
        this.age   = age;
    }

    // Method
    void bark() {
        System.out.println(this.name + " says: Woof!");
    }
}

// Creating objects
Dog d1 = new Dog("Rex", "Lab", 3);
Dog d2 = new Dog("Bella", "Poodle", 2);
d1.bark();
d2.bark();
▶ Rex says: Woof! / Bella says: Woof!

Encapsulation (getters & setters)

Hide internal data with private fields and expose them via public getter/setter methods:

Person.java
public class Person {
    private String name;
    private int age;

    public String getName() { return name; }
    public void   setName(String n) { this.name = n; }

    public int  getAge() { return age; }
    public void setAge(int a) {
        if (a > 0) this.age = a; // validation
    }
}

Person p = new Person();
p.setName("Alice");
p.setAge(30);
System.out.println(p.getName() + " is " + p.getAge());
▶ Alice is 30

Inheritance

A child class (extends) inherits fields and methods from a parent class:

Inheritance.java
class Animal {
    String name;
    void eat() { System.out.println(name + " eats."); }
}

class Cat extends Animal {
    void meow() { System.out.println(name + ": Meow!"); }
}

Cat cat = new Cat();
cat.name = "Whiskers";
cat.eat();   // inherited
cat.meow();  // own method
▶ Whiskers eats. / Whiskers: Meow!

Polymorphism (Method Overriding)

A subclass can override a parent method with @Override:

Polymorphism.java
class Shape {
    double area() { return 0; }
}

class Circle extends Shape {
    double radius;
    Circle(double r) { radius = r; }
    @Override
    double area() { return Math.PI * radius * radius; }
}

class Rectangle extends Shape {
    double w, h;
    Rectangle(double w, double h) { this.w=w; this.h=h; }
    @Override
    double area() { return w * h; }
}

Shape[] shapes = { new Circle(5), new Rectangle(4, 6) };
for (Shape s : shapes) {
    System.out.printf("Area: %.2f%n", s.area());
}
▶ Area: 78.54 / Area: 24.00

Interfaces

Interface.java
interface Flyable {
    void fly(); // abstract – no body
}

class Bird implements Flyable {
    public void fly() {
        System.out.println("Bird flaps wings!");
    }
}

Bird b = new Bird();
b.fly();
▶ Bird flaps wings!
