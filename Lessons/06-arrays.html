Arrays & Collections

Arrays store fixed-size sequences of elements. Java Collections (ArrayList, HashMap) give you resizable, feature-rich data structures.

Arrays

Arrays.java
int[] numbers = {10, 20, 30, 40, 50};

System.out.println(numbers[0]);       // 10 (first element)
System.out.println(numbers.length);    // 5

// Loop through array
for (int num : numbers) {
    System.out.print(num + " ");
}
▶ 10 20 30 40 50

2D Arrays

2DArray.java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
System.out.println(matrix[1][2]); // 6 (row 1, col 2)

ArrayList

ArrayList is a resizable array from the java.util package:

ArrayList.java
import java.util.ArrayList;

ArrayList<String> fruits = new ArrayList<>();
fruits.add("Apple");
fruits.add("Banana");
fruits.add("Cherry");

System.out.println(fruits.get(1));   // Banana
System.out.println(fruits.size());  // 3

fruits.remove("Apple");
System.out.println(fruits);            // [Banana, Cherry]
▶ Banana / 3 / [Banana, Cherry]

HashMap

A HashMap stores key-value pairs with fast lookups:

HashMap.java
import java.util.HashMap;

HashMap<String, Integer> scores = new HashMap<>();
scores.put("Alice", 95);
scores.put("Bob",   82);
scores.put("Carol", 78);

System.out.println(scores.get("Bob")); // 82

for (String key : scores.keySet()) {
    System.out.println(key + ": " + scores.get(key));
}
▶ 82 / Alice: 95 / Bob: 82 / Carol: 78
