Strings

Strings are one of the most-used types in Java. They are objects of the String class and come with dozens of built-in methods.

Creating Strings

Strings.java
String s1 = "Hello";                    // string literal
String s2 = new String("World");       // object form
String s3 = s1 + ", " + s2 + "!";   // concatenation
System.out.println(s3);                 // Hello, World!
▶ Hello, World!

Common String Methods

StringMethods.java
String txt = "  Java Programming  ";

System.out.println(txt.length());              // 21
System.out.println(txt.trim());               // "Java Programming"
System.out.println(txt.toUpperCase());        // "  JAVA PROGRAMMING  "
System.out.println(txt.toLowerCase());        // "  java programming  "
System.out.println(txt.contains("Java"));    // true
System.out.println(txt.replace("Java", "Kotlin")); // "  Kotlin Programming  "
System.out.println(txt.trim().indexOf("P")); // 5
System.out.println(txt.trim().substring(5)); // "Programming"

String Comparison

Compare.java
String a = "hello";
String b = "Hello";

System.out.println(a.equals(b));           // false (case-sensitive)
System.out.println(a.equalsIgnoreCase(b)); // true
▶ false / true
⚠️ Never use == to compare Strings! Use .equals() instead. == checks reference equality, not content.

StringBuilder (for efficient string building)

StringBuilder.java
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(", ");
sb.append("Java!");
sb.insert(0, ">>> ");
System.out.println(sb.toString());
▶ >>> Hello, Java!

String Formatting

Format.java
String name = "Alice";
int score = 95;
double gpa = 3.87654;

System.out.printf("Name: %s, Score: %d, GPA: %.2f%n", name, score, gpa);
▶ Name: Alice, Score: 95, GPA: 3.88
Format SpecifierType
%sString
%dInteger
%fFloat/Double
%.2fDouble (2 decimal places)
%nNewline
